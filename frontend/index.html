      About AKAI SORA

      AKAI SORA (紅空, “red sky”) is a self-built, real-time flight tracker created by an Aviation & Aeronautical Engineering student in Hong Kong. The project aims to demonstrate live data engineering, GIS visualization, and aerospace domain knowledge — and to stand out on LinkedIn as a portfolio piece.

      Beyond Flightradar24 / FlightAware

      • Deep engineering specs per aircraft type (engines, thrust, MTOW, range, ceiling, Mach).
      • Special-livery tracking with photo display (Pokémon jets, batik, themed liveries).
      • Airport disruption index computed live from METAR.
      • Transparent data-source status (live OpenSky vs. cached vs. demo fallback).

      Tech Stack

      Python (FastAPI) backend · Vanilla HTML/CSS/JS + Leaflet frontend · OpenSky Network live states · NOAA AviationWeather METAR · Wikimedia Commons imagery.

      Roadmap (Future Development)

      • Live weather radar overlay on the tracking map.
      • Typhoon warning system — alert for any flight path intersecting a typhoon’s forecast cone.
      • Historical replay and flight playback.
